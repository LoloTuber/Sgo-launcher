# 📗 Дневник «Сетевой город» (SgoDiary)

Неофициальное клиентское приложение для электронного дневника «Сетевой город» (СГО / NetSchool). 
Проект представляет собой две независимые версии — **для ПК (Windows)** и **для Android** — которые используют общий современный интерфейс (HTML/CSS/JS) и работают автономно. 

> **Важно:** Приложение работает в режиме **только для чтения**. Оно не отправляет данные в школьную систему, не меняет оценки и не передает ваши данные на сторонние серверы. Всё хранится локально на вашем устройстве.

---

## ✨ Основные возможности

- **📅 ДЗ на завтра:** Умный поиск ближайшего учебного дня, подробности от учителя и кнопка «Скопировать» для отправки в мессенджер.
- **📓 Дневник:** Полноценная лента с оценками (с учётом веса: x10, x20 и т.д.), темами уроков, домашними заданиями и подробностями по клику.
- **📊 Успеваемость:** Текущие оценки, средний балл и удобный подсчёт количества «5», «4», «3». Выделение долгов («точек») красным цветом.
- **🏆 Итоги:** Рейтинг предметов по среднему баллу.
- **🕒 Расписание:** Сетка звонков на обычные (40 мин) и сокращённые (30 мин) дни. Таймер обратного отсчёта до уроков и возможность добавить личные заметки.
- **🧮 Калькулятор:** Симулятор «Что если» (как изменится балл, если исправить тройку или точку) и расчет необходимого количества пятёрок до целевого среднего балла.
- **🎨 Кастомизация:** Светлая и тёмная темы. Выбор цветовой палитры интерфейса (Зелёная, Синяя, Розовая, Фиолетовая, Оранжевая).
- **🔒 Безопасность:** Ваш логин и пароль сохраняются в защищённой системной папке (`AppData` на ПК или `SharedPreferences` на Android) и никуда не отправляются.

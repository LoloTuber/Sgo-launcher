# 📗 Дневник «Сетевой город» (SgoDiary)

Неофициальное клиентское приложение для электронного дневника «Сетевой город» (СГО / NetSchool). 
Проект представляет собой две независимые версии — **для ПК (Windows)** и **для Android** — которые используют общий современный интерфейс (HTML/CSS/JS) и работают автономно. 

> **Важно:** Приложение работает в режиме **только для чтения**. Оно не отправляет данные в школьную систему, не меняет оценки и не передает ваши данные на сторонние серверы. Всё хранится локально на вашем устройстве.

---

## ✨ Основные возможности

- **📅 ДЗ на завтра:** Умный поиск ближайшего учебного дня, подробности от учителя и кнопка «Скопировать» для отправки в мессенджер.
- **📓 Дневник:** Полноценная лента с оценками (с учётом веса: x10, x20 и т.д.), темами уроков, домашними заданиями и подробностями по клику.
- **📊 Успеваемость:** Текущие оценки, средний балл и удобный подсчёт количества «5», «4», «3». Выделение долгов («точек») красным цветом.
- **🏆 Итоги:** Рейтинг предметов по среднему баллу.
- **🕒 Расписание:** Сетка звонков на обычные (40 мин) и сокращённые (30 мин) дни. Таймер обратного отсчёта до уроков и возможность добавить личные заметки.
- **🧮 Калькулятор:** Симулятор «Что если» (как изменится балл, если исправить тройку или точку) и расчет необходимого количества пятёрок до целевого среднего балла.
- **🎨 Кастомизация:** Светлая и тёмная темы. Выбор цветовой палитры интерфейса (Зелёная, Синяя, Розовая, Фиолетовая, Оранжевая).
- **🔒 Безопасность:** Ваш логин и пароль сохраняются в защищённой системной папке (`AppData` на ПК или `SharedPreferences` на Android) и никуда не отправляются.

💻 Сборка и запуск на ПК (Windows)

Для работы потребуется установленный Python 3.10+ (при установке не забудьте поставить галочку "Add Python to PATH").
Запуск из исходников (для разработки)

    Откройте терминал (PowerShell или CMD) в папке pc.

    Установите необходимые зависимости:
    bash

    py -m pip install requests pywebview pyinstaller

    Запустите приложение:
    bash

    py launcher.py

Сборка в один .exe файл

Чтобы получить готовую программу, которая запускается двойным кликом без установки Python:
bash

py -m PyInstaller --noconfirm --onefile --windowed --add-data "web;web" --name "Дневник" launcher.py

    Готовый файл Дневник.exe появится в папке dist.

    При первом запуске он создаст конфигурационный файл sgo_config.json в папке C:\Users\<Ваше_Имя>\AppData\Roaming\SgoDiary\.

    (Если приложение не запускается, убедитесь, что в Windows установлен компонент WebView2 Runtime от Microsoft).

📱 Сборка для Android

Для сборки потребуется Android Studio (рекомендуется версия Hedgehog или новее).

    Откройте Android Studio и выберите File -> Open.

    Укажите путь к папке android из этого репозитория.

    Дождитесь окончания синхронизации Gradle (внизу появится надпись BUILD SUCCESSFUL).

    Подключите телефон по USB (с включенной отладкой по USB) или запустите эмулятор.

    В верхнем меню выберите Build -> Build Bundle(s) / APK(s) -> Build APK(s).

    Нажмите на ссылку locate в появившемся уведомлении. Готовый app-debug.apk будет лежать по пути android/app/build/outputs/apk/debug/.

    Скиньте APK на телефон и установите (разрешите установку из неизвестных источников).

    ⚠️ Важно для разработчиков: Если вы вносите изменения в папку web, не забудьте скопировать обновлённые файлы в android/app/src/main/assets/web/ перед сборкой APK, иначе интерфейс на телефоне не обновится.

⚙️ Первый запуск и настройка

    При первом запуске (как на ПК, так и на телефоне) появится окно входа.

    Введите ваш логин и пароль от СГО, а также ID школы (по умолчанию 1244).

    После успешного входа данные сохранятся, и при следующих запусках приложение будет открываться сразу с вашим дневником.

    Выйти из аккаунта или сменить пользователя можно в меню Настроек (⚙️).

❓ Частые вопросы и ошибки

    Ошибка 409 «Неверный логин или пароль»: Убедитесь, что вы вводите пароль в правильной раскладке (RU/EN) и без лишних пробелов. Помните, что после 3-х неудачных попыток сервер СГО блокирует вход на 1–2 минуты.

    Не отображается интерфейс на ПК: Убедитесь, что папка web лежит рядом с Дневник.exe (если вы собирали без флага --add-data), либо пересоберите .exe с этим флагом.

    Проблемы с отчетами (Посещаемость): Для генерации отчётов используется WebSocket-соединение с серверами СГО. Если школьный сервер недоступен или блокирует соединение, данные по посещаемости могут временно не загружаться.
